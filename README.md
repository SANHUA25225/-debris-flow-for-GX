# 广西泥石流灾害点数据仓库

> 广西壮族自治区 146 个泥石流灾害点的基础数据、自然环境因子匹配结果与处理说明
> 更新日期：2026-11-14

---

## 1. 项目简介

本仓库收录广西 146 个泥石流灾害点的空间数据，以及它们与地形、地质、地貌、河网、降水五类自然地理要素的匹配结果。所有产物均以 **CSV / XLSX / SHP / TIF** 形式交付，不含制图成果。

数据按"轮次"组织，每一轮解决一类问题，都带独立的验收记录与说明文档：

| 轮次 | 解决的问题 | 主要产物 |
|---|---|---|
| 第一轮 | 从广西地质灾害矢量库中提取泥石流点 | 146 点 SHP + 明细 CSV + 地市统计 |
| 第三轮 | 与地形、地质、地貌、河网匹配 | 37 字段总表 + 5 张统计表 |
| 第四轮 | 与多年平均降水匹配 | 降水提取表 + 2 幅栅格 |
| 第五轮 | 合并两轮结果，建立综合分析数据库 | 146×46 分析表（CSV + GPKG） |

> 第二轮为事件数据库整理（洪涝—泥石流共现关系），未包含在本仓库。

## 2. 数据源

| 数据 | 来源 | 规格 |

| 降水 | 中国 1km 分辨率逐月降水量数据集（Peng et al. 2019, ESSD） | 1901—2025，2001—2020 实际使用 |

## 4. 各轮结果摘要

### 第一轮：点位提取

- 全区共 **146 个**泥石流灾害点（登记点口径）
- 原始库中 `隐患点` 字段：1 = 45 个，0 = 101 个
- 地市分布：桂林 34、梧州 29、百色 17、来宾 15、玉林 12、南宁 9、柳州 8、贺州 8、河池 8、贵港 3、崇左 2、防城港 1

### 第三轮：自然地理环境匹配

| 因子 | 字段 | 结果 |
|---|---|---|
| 高程 | `ELEV_M` | 35.6—1320.9 m，均值 408.0，中位数 348.1 |
| 坡度 | `SLOPE_DEG` | 0—41.0°，均值 17.9，中位数 17.0 |
| 起伏度 | `RELIEF_M` | 93.8—1172.7 m，均值 561.5，中位数 585.2 |
| 河流距离 | `DIST_RIV_M` | 10.7—8147 m，均值 1171，中位数 769 |
| 地层年代 | `GEO_AGE` | 146/146 匹配，无重叠 |
| 岩性 | `TYPE_RAW` | 仅 39/294 个地质面有岩性，**降级使用** |
| 地貌 | `LANDFORM` | 145/146 within，1 点 200 m 内就近赋值 |

形态类型构成：低海拔小起伏山地 85、低海拔中起伏山地 29、低海拔丘陵 22、中海拔中起伏山地 5、低海拔台地 3、低海拔平原 1。

### 第四轮：降水匹配

## 5. 口径与已知问题（引用前必读）

1. **146 点是登记点，不是事件数**。与洪涝—泥石流事件库的记录口径不同，**不可相加、不可互相校验**。
2. **45 / 101 是"隐患点"字段拆分**，不等于"历史灾害点"。全库无发生时间字段，`灾害等级` 全空、`毁坏房屋` 全 0，因此只能称"在册隐患点 / 非隐患点"。
3. **岩性不可用**。1:500 万地质图 294 个面中仅 39 个有岩性代码，只能做"年代 + 火成岩二分"，**禁止用年代反推岩性**。
4. **地貌分区的起伏度系统性偏低**。分区图把 58.2% 的点判为"小起伏山地（200—500 m）"，但实测中位数 585 m。定量分析请用 `RELIEF_M`，`LANDFORM` 仅作定性参考。
5. **DEM 为 DSM**，含林冠高度，植被茂密区高程略高于地面。
6. **降水是气候背景，不是致灾降雨**。且该数据集在桂西、桂中系统性偏高 8—10%，绝对量引用需谨慎。
7. **河流距离不等于沟道距离**。最近的河网线段可能是干流，不代表泥石流沟口。
8. **坐标系**：原始数据 EPSG:4326 未改动；距离计算用 EPSG:32649（UTM 49N，广西最西端距离尺度偏大 0.51%）；面积统计用 EPSG:6933。

## 6. 复现方式

环境：Python 3.11，依赖 `fiona`、`rasterio`、`shapely`、`netCDF4`、`openpyxl`、`numpy`、`scipy`。

```bash
# 第三轮：地形、地质、地貌、河网
py -3.11 第三轮_空间匹配验收/生成脚本_spatial_match.py

# 第四轮：降水
py -3.11 第四轮_降水匹配/生成脚本_降水匹配.py
```

两个脚本顶部的路径常量需按本机实际数据位置修改。降水脚本要求 nc 文件放在 **ASCII 路径**下（netCDF4 无法读取含中文的路径）。
