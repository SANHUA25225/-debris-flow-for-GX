# 广西 146 个泥石流点 · 第三轮空间匹配验收说明

> 验收对象：广西全区地质灾害数据库中提取的 146 个泥石流灾害点
> 验收内容：与 DEM、地质、地貌、河网四类自然地理数据逐项空间匹配
> 生成日期：2026-11-13

---

## 1. 本轮目标

前两轮已验证数据本身可用（第一轮：146 条记录、EPSG:4326、位置正常；第二轮：编号唯一、隐患点 45/101 分类一致、无重复、经纬度一致）。

本轮要回答的是：**每个泥石流点能否正确匹配到它所在位置的地形、岩性、地貌和河流环境？**

这是后续解释"广西泥石流点为什么集中在某些地区"的前提。

## 3. 坐标系处理

| 对象 | 处理方式 | 理由 |
|---|---|---|
| 原始 146 点 | **保留 EPSG:4326，不覆盖** | 原始数据不可改动 |
| DEM | 保留原投影，直接采样 | 采样不要求投影一致，转换会引入重采样误差 |
| 地质 / 地貌面 | 保留 4326，按度计算包含关系 | 无需重投影 |
| 河流距离计算 | 点与河线均转 **EPSG:32649**（UTM 49N） | 距离必须以米计 |
| 全区面积统计 | 不得使用 49N，改用 **EPSG:6933** 等积投影 | UTM 非等积 |

**投影变形实测**（49N 中央经线 111°E）：

| 位置 | 偏离中央经线 | 距离尺度误差 | 面积尺度误差 |
|---|---|---|---|
| 东端 112°E | 1° | ≈ 0 | ≈ 0 |
| 中部 108°E | 3° | +0.11% | +0.22% |
| 西端 104.45°E | 6.55° | **+0.51%** | **+1.03%** |

结论：单点距离用 49N 可接受（最大偏大 0.5%）；桂西面积统计必须换等积投影。

## 4. 方法与参数

### 任务 1 · DEM 高程匹配
- 逐点用 `rasterio.sample()` 提取像元值，写入 `ELEV_M`
- 命中判定：值非 NoData（NoData = -32767）且有限
- 异常值检查：< 0、> 3000 m

### 任务 2 · 岩性匹配
- 空间关系：`within`（用 STRtree 加速，逐点判断面包含）
- 同步计算点到地质面**边界的最近距离**（米），用于识别边界点
- 保留原始字段：`GEO_AGE`（GLG 原始代码）、`TYPE_RAW`（原始 TYPE），不预合并碳酸盐岩

### 任务 3 · 地貌匹配
- 空间关系：`within`
- 若点落在地貌面外，且到最近面距离 < 200 m，则按最近面赋值并标记 `LF_MATCH = 2`（本批 1 例，14 m）
- 距类型边界 < 30 m 的点单独标记，**不强行改类型**

### 任务 4 · 河流距离匹配
- 点与全部 HYDL 线统一投影到 EPSG:32649
- 用 STRtree 最近邻查询，计算欧氏距离（米）
- 同时回填最近河流名称 `RIV_NAME`

### 任务 5 · 坡度与地形起伏度
- **坡度**：Horn 三阶差分（3×3 邻域），在 4326 栅格上按该纬度实际米距计算
  - 每度经线长度取 `111412.84·cosφ − 93.5·cos3φ`，每度纬线取 `111132.954 − 559.822·cos2φ + 1.175·cos4φ`
  - 不做重投影，避免重采样改变原始高程
- **起伏度**：以点为中心、半径 **2.1 km 圆窗**内的最高与最低高程之差，与地貌分区派生所用窗口一致
- **分级**：沿用李炳元 1:100 万形态地貌方案（<30 平原 / 30–70 台地 / 70–200 丘陵 / 200–500 小起伏 / 500–1000 中起伏 / >1000 大起伏）

## 9. 已知限制

1. **DEM 是 DSM 不是 DTM**。Copernicus GLO-30 含林冠与建筑高度，山区高程可能虚高 5–20 m。用于高程、起伏度、坡度无碍；精细水文分析（流向、汇流）建议改用 SRTM 或做冠层校正。
2. **DEM 实际分辨率 30.9 m**（1 弧秒），不是严格 30 m；广西纬度下东西向约 28 m。
3. **岩性比例尺不匹配**。1:500 万图斑平均约 808 km²，一个点落在某个面上只代表"位于该地层区"，不能代表点位所在山坡的岩性。岩性细分与"碳酸盐岩 vs 碎屑岩"的判断均不可由本数据支撑。
4. **地貌为派生数据**。仅用海拔 + 2.1 km 起伏度两个形态指标，未区分成因（喀斯特溶蚀、流水侵蚀、构造山地），不能等同于中科院 1:100 万地貌图。
5. **河流距离不等于泥石流沟道距离**。1:100 万 HYDL 漏掉大量小沟道，最远点达 8,147 m，这个数值不能解释为"离水很远"。论文中只能表述为"距最近河网距离"。
6. **投影变形**。距离在 UTM 49N 计算，桂西最西端偏大约 0.5%；面积统计不得使用 49N。
7. **地貌分区与点尺度起伏度不一致**。全库仅 73/146 类型一致。已用 76 m 同窗口复算排除分辨率因素，判断为该分区图本身起伏度偏低，故 `LANDFORM` 仅可用于定性参考，定量起伏度请用 `RELIEF_M`。
8. **14 个点坡度 < 5°**（占 9.6%）。泥石流物源区通常坡度较大，这批低坡度点可能位于沟口堆积区或河谷底部，使用坡度做易发性分析时应单列核查，不宜直接与坡面型样本混算。

## 11. 复现说明

`生成脚本_spatial_match.py` 使用 Python 3.11 + fiona / rasterio / shapely / openpyxl 完成全部计算，不依赖 QGIS 手工操作。

运行前需修改脚本顶部的路径常量（`PTS`、`DEM`、`GEO`、`LF`、`GDB`），指向本机数据位置；随后执行：

```bash
py -3.11 生成脚本_spatial_match.py
```

脚本会重新输出 Excel 与 CSV，并在控制台打印匹配率、边界距离、年代与岩性分布等校验值，可用于复核。
